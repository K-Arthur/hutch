# Surface brief — Hutch operator workspace (SPA at `/`)

Mode: **Operate**. Visitor: the machine's owner, supervising their own bots. Targets:
desktop (1280–1920) and phone (320–430, keyboard open). Surfaces: Studio conversation,
Overview, Bots, Bot settings, Runs, Run detail, Approvals, Connections, first-run welcome.

## Direction contract

THESIS: a quiet graphite console where the truth of the machine is always the loudest
thing on screen — the category default it refuses is the flat dark dashboard of KPI
boxes and decorative status colour.

OWN-WORLD: emerald lineage for brand + primary action with near-black ink; azure
interaction only; amber only for person-needed-now; rose for failure. One rounded
scale (8/12/18/22/100) after an explicit user override of the earlier square
language. System sans for language at reading sizes; mono strictly for measured
values. Elevation by offset+blur shadow + hairline, never glow.

STORY: the operator opens to their conversation, sees what bots are doing from real
server state, decides consequential approvals with the exact facts, and leaves with
a trustworthy accounting of tokens, time and effects.

FIRST VIEWPORT: 272px sidebar (brand, nav, searchable roster, footer truth) +
56px context header carrying bot identity left, view actions right, and the
workflow status cluster (working / queued / needs-you, quiet when idle) + a 760px
conversation column: muted slate user bubbles right, plain agent text left,
borderless tool lines under a collapsed "N steps" summary, composer pinned bottom.

SIGNATURE: the thinking dots (shown only while the server reports a run active)
plus a simple flat 2D Bot character in the first-run welcome and roster. Each
Bot keeps one editable, name-stable coloured silhouette with two white glints;
status remains a separate, labeled indicator. Detailed original 3D character
art is reserved for marketing pages and is not loaded into the working app.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish
review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
