## 4. Knockout search procedure

Queries, recorded before searching:
- [ ] Word: exact "Hutch" and "hutch" in each register's supported syntax, plus a dated expansion set
  (case, punctuation, spacing, product-context phrasing, phonetic/visual neighbours), frozen before any result is reviewed.
- [ ] Design: Vienna-coded figurative search for a hexagonal outline and a centre-dot device; record
  codes and the image-search interface where available.
- [ ] One pass per class in scope (9/42; 35/41 only with attached offer evidence), word and design separate.
- [ ] Common-law: general web, app stores, GitHub org/user names, package registries, social handles
  and domains - one recorded row each.

Method and fields (one row per retrieval; URL + retrieval date is the evidence convention):
- [ ] Record interface, URL and retrieval date. TMview/eSearch are indexes only; the official
  register confirms every hit. Attempt a screenshot/archive capture; where unavailable write
  "not captured - reason" (B1).
- [ ] Date (ISO 8601, America/Vancouver), register/interface, exact URL and query string, filters
  (class, jurisdiction, status), result count.
- [ ] Outcome HIT / NO HIT / UNREACHABLE; for HIT quote mark, number, owner, class, status and a
  goods/services excerpt (max 25 words); analyst; protocol version v0.1.

Evidence retention: root by adoption path - Option A docs/brand/evidence/clearance/, Option B
.pipeline/brand/2026-10/evidence/clearance/ (section 8). Names
YYYY-MM-DD_<register>_<class>_<query-slug>.<ext>; screenshots share the slug. Raw and unedited:
corrections are new dated rows citing the superseded row; nothing deleted; logs, screenshots and
AI-use records stay together. A missing capture is a gap, never a pass.

## 7. AI-use and provenance policy

- [ ] Internal concepting only; no AI-assisted concept is published, shipped or used outside this
  pipeline without a completed sign-off and the gates above.
- [ ] No prompt names an existing mark, brand, product, person or studio, and no prompt asks for a
  specific existing mark to be reproduced or imitated.
- [ ] Provenance record for every generated concept: tool; model/version; date; terms snapshot
  (URL + retrieval date); prompt text; output filename or hash; human operator; what was kept,
  rejected and why (plan [R.3] AI-tool policy fields).
- [ ] Human redraw: final mark and wordmark geometry is redrawn or constructed by a human; AI output
  is reference only and never the master; redraw author and date recorded.
- [ ] Authorship: the model is a tool, never the author; commits stay maintainer-authored with no
  AI-tool trailers. Concepts without a complete record are dropped; records live with the evidence
  set (section 4) and are listed in the sign-off.
