# Cost, context and routing failure evidence (2026-10-11)

This is a narrow source ledger for the cost-guardrails, context-continuity and task-routing work. Public issue threads are user reports,
not controlled experiments or prevalence estimates. A closed issue is not treated as proof that the installed product behavior has changed.
The OpenRouter calls recorded here were unauthenticated metadata GETs only. No account data, provider key or paid generation was used.

## Verification boundary

Public metadata freshness and endpoint field presence were checked on 2026-10-11, including one long-context tier. No paid model call, provider-account billing inspection, endpoint-affinity experiment, live tool-capability evaluation or full Hutch task-quality comparison was run. Cost controls are admission estimates; the provider remains the authority for its bill. Current Hutch compaction approval still waits inside its owning run worker, although it releases Hutch's local inference slot before asking; making approval wait fully suspend/resume would require a durable run continuation design and remains an open limitation.
