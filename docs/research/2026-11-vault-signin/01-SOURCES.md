Access date for every row: **2026-11-06** unless the row says otherwise. This extends
`docs/security/vault-and-authentication/research.md` (accessed 2026-10-31); it does not repeat it.

How to read this file:

- Each source has an id (`A1`, `B3`, `C7`, `D12`). `03-LESSONS-AND-DECISIONS.md` and
  `02-FAILURES-AND-COMPLAINTS.md` cite these ids.
- "Relied on" is a claim the page actually made, quoted where the exact wording matters. Pages were
  read through a fetch tool that returns an extract answering a stated question, so a quote is what
  the extract returned for that page on that day, not a full read of the page.
- "Effect" is what the source changed in the Hutch plan. A source that changed nothing says so.
- Other products' pages are a checklist and a source of pitfalls. Nothing here copies their names,
  wording or behavior. Marketing and product docs describe intent, not proven implementation.
- Unreachable sources are recorded as unreachable. No page was fetched through a challenge.
