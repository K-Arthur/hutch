A connector is a program or endpoint that gives an assistant tools for another service. Installing a connector authorizes nothing: it becomes available only when you grant one of its tools to a named assistant.

{{ icon("layers", 14) }}Provider accounts {{ icon("cpu", 14) }}Model routes
{{ icon("shield", 18) }}

Local connectors run inside Hutch's sandbox. A local server starts with no host network, no inherited environment, one writable directory and read-only access to the paths you reviewed. Its executable and every reviewed path are fingerprinted when you save the definition; if either changes, Hutch refuses to start it until you review it again.

Credential values are never stored. A definition may name an environment variable, and Hutch reads it when the server starts.

{{ icon("layers", 18) }} Installed connectors

Each connector reports its own state. "Capabilities discovered" means Hutch has read the server's tool list; it does not mean any assistant may use it.
